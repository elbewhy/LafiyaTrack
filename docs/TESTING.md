# LafiyaTrack Testing Plan

## Objective

Ensure LafiyaTrack works correctly before deployment and pilot testing.

---

## Functional Testing

### Authentication

- User can log in
- User cannot log in with invalid credentials

---

### Child Registration

- Register a new child
- Prevent duplicate records where possible
- Save records successfully

---

### Nutrition Screening

- Record MUAC
- Record edema assessment
- Record weight
- Record height
- Automatically classify nutritional status

---

### Referral

- Generate referral
- Update referral status

---

### Follow-up

- Schedule follow-up
- Record follow-up visit

---

### Synchronization

- Save data offline
- Synchronize successfully when internet becomes available

---

## Performance Testing

- Fast page loading
- Low memory usage
- Smooth operation on entry-level Android phones

---

## User Acceptance Testing (UAT)

Pilot the application with Community Health Extension Workers (CHEWs) and collect feedback for improvements.
