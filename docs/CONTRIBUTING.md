# Contributing to LafiyaTrack

Thank you for your interest in contributing to LafiyaTrack.

## Development Principles

- Write clean and readable code.
- Follow the project structure.
- Document new features.
- Test before submitting changes.

## Git Workflow

1. Create a new branch.
2. Make your changes.
3. Commit with a clear message.
4. Submit a Pull Request.

## Code Style

- Use meaningful variable names.
- Keep functions small.
- Add comments where necessary.

Together, we can build a reliable offline-first digital health platform for improving child nutrition.
