# LafiyaTrack

LafiyaTrack is an offline-first digital health platform developed by A&M TECH FOUNDRY to support Community Health Extension Workers (CHEWs) in screening, monitoring, referring, and following up children at risk of malnutrition.

The platform is designed for low-connectivity environments and enables reliable data collection, timely interventions, and data-driven decision-making for health facilities, government agencies, and development partners.

## Key Features

- Offline-first architecture
- Child registration
- MUAC screening
- Bilateral edema assessment
- Nutrition classification
- Referral management
- Follow-up tracking
- Synchronization when internet is available
- Dashboard and analytics

## Technology Stack

- Frontend: Vue.js + Bootstrap (PWA)
- Backend: FastAPI (Python)
- Database: SQLite (MVP), PostgreSQL (Production)
- Offline Storage: IndexedDB
- Hosting: GitHub Pages + Render
